[GGJ-2014] 活動參與心得

第一次參加 Global Game Jam 2014 的活動心得：48 小時做遊戲，重新看見遊戲開發社群、團隊協作與台灣遊戲產業的熱情。

第一次參加 Global Game Jam 2014，最大的收穫不是完成一款沒有 Bug 的遊戲，而是在 2014 年 1 月 24 日到 1 月 26 日這三天裡，重新看見自己對遊戲的熱愛，也看見台灣遊戲開發者願意用專業能力實踐想法的生命力。

製作遊戲不是夢想，我們做到了。這張照片記錄的是最後發表後的感動時刻，也記錄了三天沒有好好睡覺、沒有好好吃飯，卻還是把作品推到台上的那種疲累與興奮。

Global Game Jam 2014 對第一次參加者來說是什麼體驗？

Global Game Jam 2014 是一次把遊戲熱情拉回現實的活動。參與者必須在三天內組隊、發想、製作並發表遊戲，過程比想像中混亂，也比想像中更讓人感動。

2014 年 1 月 24 日到 1 月 26 日，是我第一次參加 Global Game Jam 的日子。那幾天對我而言很特別，因為我看見台灣開發者對遊戲的熱情與想法，也看見台灣遊戲產業仍然有一股很珍貴的生命力。

Global Game Jam 是一個全球同步舉辦的遊戲創作活動。參與者會在限定時間內依照當年主題組隊做出遊戲，作品完成度不一定整齊，但每一組都要把發想、取捨、實作和發表全部走過一次。

參加 Global Game Jam 之前，我怎麼看待自己和遊戲的關係？

參加 Global Game Jam 2014 之前，我一度把玩遊戲視為不夠上進的事。Global Game Jam 2014 讓我意識到，熱愛遊戲不必等於逃避現實，也可以轉化成創作與專業。

以前的我非常沉迷電玩，尤其是線上遊戲。沉迷到家人其實很不能諒解，因為玩遊戲不只影響念書時期的課業，也很容易影響工作節奏。那時候常常趕著下班出團拓荒，連自己也不懂到底是在拼什麼。

也許是不想輸，也許是比較心態。我玩遊戲玩得很認真，每次都想玩到最強；可是現實中的我，並沒有像遊戲裡那樣順利。

2011 年，我離開線上遊戲，專心拼工作。台灣社會裡，玩遊戲常常被和萎靡、不上進、不自律放在一起。曾經連我自己也覺得，玩遊戲是一件不對的事，是毫無收穫的空轉。

直到 Global Game Jam 2014，我遇見了這些夥伴。

Global Game Jam 2014 為什麼讓我重新理解遊戲開發社群？

Global Game Jam 2014 讓我看見遊戲開發社群的專業與自律。許多參與者熱愛遊戲，也各自有工作、技能與成就，遊戲不是逃避生活，而是共同創作的語言。

這一次的 Global Game Jam 2014，有許多熟面孔是過去參加過、又再次回來的人，例如我們這隊的橘之介。從他們身上，我看到很直接的熱情與衝勁。

我們不是一群沉迷遊戲的 Loser。我們都擁有各自的專業技能與工作成就，我們熱愛玩遊戲，但也沒有忘記該過的現實生活。

更準確地說，我們是一群曾經熱愛過遊戲、曾經和遊戲一起成長的人。我感動於我們有相似的生命記憶：那些陪伴我們長大、讓我們熱愛、卻也讓我們被責罵的遊戲記憶。

因為對遊戲的愛，我們聚集在 Global Game Jam 2014 台灣微軟會場，為自己的遊戲之夢畫出一個開端。

48 小時做遊戲，最難的是創意發想還是開發執行？

48 小時做遊戲最難的是從發想卡關切到可執行方案。Global Game Jam 2014 的第一晚，我們在疲累中放下完美主題，才真正開始把遊戲做出來。

三天內要發想、企劃、實作完成一款遊戲，真的不容易。2014 年 1 月 24 日剛好是很多公司的尾牙，有些組員陸續很晚才到會場。先到的人必須不停重述討論內容，讓後到的人能進入狀況，也不能抹殺新的遊戲創意。

時間一直過去，半夜十二點時，全隊依然僵持不下。大家的眼神從熱血慢慢變成呆滯，話題也從當年主題「We don't see things as they are, we see them as we are.」，慢慢變成聊自己喜歡的遊戲，看影片，甚至下載來玩。

凌晨一點半，橘之介突然提議：「不然，我們不要管主題好了！我一直想做一款潛行的遊戲，就先來做看看？」

全隊已經沒有力氣繼續推翻重想，於是這個方向就在大家精疲力竭的狀況下通過了。現在回頭看，那不是最漂亮的企劃流程，但很像真實開發：當時間不等人，團隊必須做出一個可以前進的決定。

Global Game Jam 2014 的開發過程給了我哪些協作提醒？

Global Game Jam 2014 的開發提醒是：短期協作要早點縮小範圍，並誠實面對團隊缺口。沒有美術、框架不熟、關卡企劃太多，都會在最後一天變成壓力。

第二天才是地獄的開始。這次活動中，我和另一位程式 Vincent 協同開發；關於短期多人協作的程式心得，我後來另外整理成「GGJ-2014 遊戲開發心得」。

這一組很悲慘地沒有美術，所以兩位程式都必須同時寫 code、同時畫介面。隊長頹廢哥又很認真地企劃每一個遊戲關卡，甚至每關都有各自代表的寓意。再加上我當時接觸過的遊戲框架與遊戲引擎數量不夠，很多功能幾乎都要從頭打造。

第三天，我們竟然完成 3 個主題、6 個小關卡，連我自己都有點意外。第二天下午的中途發表明明很糟，最後作品也還有 Bug，外觀也不漂亮，但我仍然以這一隊為榮。

我們的作品是 DeTOUR - 繞行改道。當時我們已經決定會繼續修改、完善這個遊戲，並嘗試讓遊戲在 iPhone 與 Android 平台上架。

Global Game Jam 2014 最後發表讓我看到什麼？

Global Game Jam 2014 最後發表讓我看到，完成度不是活動唯一價值。每一組作品背後都有取捨、熱情與限制，真正重要的是參與者願意把想法推到可展示的程度。

最後一天，大家的成果發表讓人驚豔。短短幾天裡，每一組都從發想到實作走了一輪，這件事本身就很不容易。

在我們場次的發表作品中，The Brick Walls 是我最喜歡的一組。遊戲設計很有創意，關卡設計和畫面風格也做得很成熟。另一組 iii see 的概念我也很喜歡，我們這組的成員一致認為那是最符合本屆主題的一款遊戲。

這一次 Global Game Jam 2014，每一組作品的完成度都不一樣。但我覺得活動最重要的是過程。參與者從中體驗到自己並不孤獨，台灣仍然有許多熱愛遊戲的人，願意把專業能力投注在不容易起色的遊戲產業裡，燃燒熱情去實踐夢想。

因為有這些人，台灣的遊戲業才有機會慢慢走向更好的方向。

Global Game Jam 2014 給第一次參加者的心得整理

Global Game Jam 2014 給我的心得是：不要等條件完整才開始做遊戲。短時間開發會暴露團隊限制，但也會讓每個人更快看見自己真正能貢獻的位置。

如果把這次活動整理成給第一次參加者的提醒，我會留下幾件事：

提醒實際感受
發想要收斂主題可以討論很久，但作品需要一個能在 48 小時內做完的核心玩法。
團隊缺口要早點承認沒有美術就要降低畫面期待，或把視覺風格改成能被程式支撐的形式。
功能不要全從零開始熟悉工具、框架與素材流程，會直接影響最後能完成多少內容。
發表不是驗收完美度發表是把想法推到可被看見，Bug 與粗糙都是短期創作的一部分。
熱情需要專業承接喜歡遊戲很重要，但真正讓作品成形的是企劃、程式、美術、溝通與取捨。

這些提醒不是活動後的漂亮總結，而是三天裡一路撞出來的感覺。Global Game Jam 2014 讓我重新相信，遊戲開發不是遙遠的夢，只是需要一群願意一起做下去的人。

常見問題

QGlobal Game Jam 2014 適合第一次參加遊戲開發活動的人嗎？

Global Game Jam 2014 很適合第一次參加遊戲開發活動的人，因為活動會把組隊、發想、實作和發表全部濃縮在三天內。第一次參加者會很累，但也會快速理解遊戲開發不是只有寫程式或想點子。

Q沒有美術也能參加 Global Game Jam 嗎？

沒有美術也可以參加 Global Game Jam，但團隊要很早面對視覺限制。這次我們沒有專職美術，最後由程式同時處理介面與開發，作品能完成，但壓力和取捨都變多。

QGlobal Game Jam 的主題一定要完全照著做嗎？

Global Game Jam 的主題是創作起點，不是保證作品成功的唯一答案。這次我們一開始卡在主題，最後選擇先做一直想做的潛行玩法，再把作品推到能發表的程度。

Q48 小時遊戲開發最容易失控的是什麼？

48 小時遊戲開發最容易失控的是範圍。關卡、機關、介面、Bug 修正與素材處理都會吃時間，所以團隊越早縮小核心玩法，越有機會在最後一天完成作品。

QGlobal Game Jam 的價值是作品完成度嗎？

Global Game Jam 的價值不只在作品完成度，也在於創作者把想法做成可展示作品的過程。作品可能粗糙、有 Bug，但參與者會從協作、取捨與發表中學到真實開發的節奏。
