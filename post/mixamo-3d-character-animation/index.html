Mixamo：你的3D角色動畫工廠

Mixamo 是 Adobe 提供的免費線上 3D 角色動畫平台，上傳 FBX 模型或選用內建角色，即可自動套用數千種預設動畫並匯出，適合遊戲開發、VR/AR 創作與動畫製作快速出稿。

Mixamo 是一個提供自動 3D 角色動畫服務的線上平台。它讓我能夠選擇並自定義 3D 角色，並應用各種預設的動畫，對於遊戲開發者、動畫製作人和其他 3D 創作者非常實用，能夠顯著加快製作流程。我在需要快速幫角色加上走路、跑步等動作時，都會先到 Mixamo 試一輪。

Mixamo 是什麼？可以怎麼開始使用？

Mixamo 是一個提供自動 3D 角色動畫服務的線上平台，可以在 https://www.mixamo.com/ 直接試用你的 3D 模型。

使用方式有兩種：一是上傳自己的 FBX 模型檔案，套用線上多樣的動作；二是直接拿線上提供的角色，套入 Animation 裡面的角色動作。

該平台支持從現有的 3D 模型中生成動畫，並提供動畫調整功能，以滿足不同的需求。Mixamo 對於遊戲開發者、動畫製作人和其他 3D 創作者非常實用，能夠顯著加快製作流程。

Mixamo 提供了哪些主要功能？

Mixamo 的功能圍繞「上傳模型 → 挑動畫 → 自動套用 → 調整匯出」這條流程，主要功能包括：

  • 龐大的動作資料庫： Mixamo 提供了數千種預製的動畫，涵蓋了各種角色、動作和風格。
  • 自動套用： 你只需上傳你的3D模型，選擇想要的動畫，Mixamo就會自動將動畫套用到你的模型上，並進行調整，使其符合模型的比例和骨架結構。
  • 客製化： 你可以對動畫進行調整，例如改變動畫的速度、調整角色的姿勢等，以達到你想要的效果。
  • 匯出多種格式： Mixamo 支援多種3D軟體常用的檔案格式，方便你將動畫匯出到你的專案中。
  • 社群功能： Mixamo 有一个活躍的社群，你可以分享你的作品、與其他使用者交流，並獲得啟發。

為什麼選擇 Mixamo？它有哪些優勢？

相較於傳統的動畫製作方式，Mixamo 最直接的價值就是把「做動畫」變成「挑動畫」：

  • 節省時間： 相較於傳統的動畫製作方式，Mixamo 可以大幅縮短動畫製作的時間。
  • 降低成本： 你不需要雇用專業的動畫師，就能製作出高品質的動畫。
  • 易於使用： 即使你不是動畫專業人士，也能輕鬆上手。
  • 靈活性： Mixamo 提供了高度的客製化功能，讓你能夠創造出獨特的動畫。

Mixamo 適合用在哪些應用場景？

我實際會用到 Mixamo 的情境，多半集中在需要快速讓角色「動起來」的專案：

  • 遊戲開發： 為遊戲角色製作各種動作，如走路、跑步、跳躍、戰鬥等。
  • 虛擬實境/增強實境： 為虛擬角色製作動畫，使其更生動。
  • 動畫製作： 快速製作短片、動畫廣告等。
  • 電影特效： 為電影中的角色製作動作捕捉動畫。

常見問題

QMixamo 是免費的嗎？

是的，Mixamo 是 Adobe 提供的免費線上服務，註冊 Adobe 帳號後即可上傳模型、套用動畫並下載。對個人創作者與小型團隊來說，幾乎沒有使用門檻。

QMixamo 支援哪些模型與匯出格式？

上傳時建議使用帶有類人骨架的 FBX 或 OBJ 模型，Mixamo 會自動辨識並綁定骨架。動畫完成後可匯出 FBX 格式（可選擇是否含皮膚、每秒幀數等選項），再匯入 Unity、Unreal 或 Blender 等軟體繼續使用。

Q上傳的模型一定要是類人角色嗎？

基本上是的。Mixamo 的自動綁定是針對類人（humanoid）骨架設計的，四足動物或機械結構無法正確套用動畫。角色越接近標準人形比例，自動套用的效果就越好。

QMixamo 的動畫可以自行調整嗎？

可以。平台上可調整動畫速度、手臂姿勢（例如調整 Overdrive 幅度）、起始與結束時間等參數，調整完再匯出即可。若需要更細緻的修改，可以匯入 Blender 等軟體再編輯關鍵影格。
