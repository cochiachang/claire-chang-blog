2022 Taipei Women in Tech Honorees 得獎經驗與科技職涯觀察

整理 2022 Taipei Women in Tech Honorees 得獎過程、Women Who Code 參與經驗與女性工程師職涯觀察。

2022 年，我獲選為 Taipei Women in Tech Honorees。

對我來說，這次獲選真正重要的並不是多了一個獎項，而是讓我第一次很清楚地感受到：一個工程師的價值，不一定要透過「證明自己比別人技術更強」才能被看見。

在成為工程師超過 15 年之後，我已經很習慣待在男性占多數的研發環境裡。但加入 Women Who Code Taipei、認識更多女性科技工作者之後，我才發現，原來很多過去以為只是自己的問題，其實是許多女性工程師共同經歷過的職涯感受。

這也是為什麼，相較於「得獎」本身，我更想記錄這段經歷帶給我的改變。

我為什麼會獲選 2022 Taipei Women in Tech Honorees？

我獲選 2022 Taipei Women in Tech Honorees 的契機，來自 2021 年參與 Women Who Code Taipei 社群。我從主持活動、擔任技術分享講者開始，後來受邀成為 WWC Taipei 核心志工，並因為持續投入社群而獲得推薦。

一開始，我其實沒有特別想過要透過社群替自己累積什麼。

2021 年，我主持了幾場 Women Who Code 的活動，也以講者身分分享自己熟悉的技術主題。後來受到邀請，成為 Women Who Code Taipei 的核心志工成員。

因為持續參與活動、分享技術，也投入社群工作，我的表現獲得社群夥伴肯定，進而被推薦參與 Taipei Women in Tech Honorees 的選拔。

真正讓我印象深刻的，反而不是選拔過程，而是後來的慶祝活動。

當我實際遇見其他獲選者時，我才發現現場有非常多優秀的女性科技工作者，而且每個人的專業、經歷與人生路徑都不太一樣。

那是我第一次很強烈地感受到：

原來科技社群不一定只能討論「誰的技術比較強」。

Women Who Code Taipei 為什麼讓我對科技社群改觀？

Women Who Code Taipei 讓我感受到，科技社群除了交換技術知識，也可以是一個讓人認識彼此、理解不同職涯選擇，並重新看見自己價值的地方。

過去待在以男性工程師為主的技術環境時，我很習慣大家討論框架、程式語言、系統架構，或最近又學了什麼新的技術。

這些交流當然很重要。

但我自己其實一直不是很擅長用「我知道多少技術」來證明自己的能力。

進入 Women Who Code Taipei 之後，我感受到另一種很不一樣的交流方式。

大家除了會問：

「你最近在做什麼技術？」

也會想知道：

「你是誰？」

「你對什麼事情有興趣？」

「為什麼你會想做這件事情？」

「你怎麼看待自己的工作與職涯？」

這些問題看起來不像技術問題，卻讓我第一次覺得，工程師不需要只剩下一張技術能力清單。

技術很重要，但一個人的經驗、觀點、選擇，以及她想解決什麼問題，同樣構成了她的專業價值。

女性工程師真正的職涯困境是什麼？

以我超過 15 年的研發工程經驗來看，女性工程師遇到的困境不一定都是明確的性別歧視。有些困境反而更難描述：當團隊裡大多數的人都和你不同時，你可能很難產生「我是這個群體一分子」的感覺。

我過去主要待在純研發工程環境，而這類團隊長期以男性工程師居多。

很多時候，沒有人真的對你說「因為你是女生，所以你不能做這件事」。

但你仍然可能感覺自己和多數人不太一樣。

看事情的方法不同、在意的事情不同、溝通方式不同，甚至下班之後聊天的話題與建立關係的方式也可能不同。

久了之後，這些差異會影響很多事情。

例如你是否容易和同事建立工作以外的交情、能不能自然加入非正式的資訊交流，或者能不能產生「我們是一群一起打拼的夥伴」的感覺。

這些事情很難寫在職務說明裡，卻真實影響一個人在團隊中的歸屬感。

技術能力和「很會講技術」其實是兩回事

工程師的技術能力，不應該只用他有多會談論新技術、表達得多有自信，或多擅長展現自己的專業來判斷。真正的工程能力，最後還是要回到能不能理解問題、處理複雜度，以及把系統真正做出來。

這件事也是我工作很多年之後才慢慢理解的。

我不是那種很喜歡一直談論最新框架，或不斷強調自己技術能力有多強的人。

但回頭看自己做過的專案，我處理過的問題並不簡單。

我的軟體開發經歷橫跨圖形、動畫、遊戲、HTML5、即時串流與影像辨識，也長期接觸效能與複雜運算邏輯。

除了程式開發之外，我也熟悉 Windows、Linux 伺服器以及 WebSocket 等通訊技術。

這讓我在處理一個問題時，通常不會只從程式語言本身思考，而是會一起看作業系統、網路、硬體設備與實際應用環境。

後來我才逐漸理解：

不喜歡展現自己的技術，不代表技術能力比較差；不習慣和別人比較，也不代表沒有競爭力。

只是每個工程師展現專業的方式不一樣。

為什麼很多優秀的女性工程師仍然會懷疑自己？

冒牌者症候群會讓一個已經具備能力的人，仍然懷疑自己的成果是否只是運氣，或認為別人其實比自己優秀很多。加入女性科技社群之後，我才發現這並不是只有我會出現的感受。

這可能是我加入 Women Who Code 之後，最意外的一個發現。

我遇到了很多明明非常優秀、勇敢，而且有能力的女性科技工作者。

但聊天之後卻發現，很多人也曾經懷疑過自己。

「我真的有那麼厲害嗎？」

「是不是只是剛好？」

「其他人好像都比我懂很多。」

當一個人長期待在和自己不同的群體裡，很容易把「我和大家不一樣」慢慢解讀成「是不是我不夠好」。

但在 Women Who Code Taipei，我看到很多和自己有類似感受的人。

我才開始重新理解這件事：

有時候，我們不是不夠好，而是不夠清楚自己的好。

這個獎對我真正的意義是什麼？

2022 Taipei Women in Tech Honorees 對我的意義，不只是一次科技女性的公開表揚，而是讓我重新看見自己多年工程職涯所累積的價值，也讓我理解社群可以成為科技工作者重新認識自己的地方。

如果只從履歷來看，這可能就是多了一筆：

「2022 Taipei Women in Tech Honoree」。

但對我來說，它真正留下來的不是這行文字。

而是我開始知道，一個工程師的價值不只有會多少程式語言、用過多少框架，或是不是團隊裡最會談論新技術的人。

那些真正困難的專案、曾經解決過的問題、跨領域累積的經驗、願意分享的知識，以及一路走到現在形成的思考方式，其實都構成了自己的專業。

而一個好的社群，有時候最大的價值，也不是再教會你一項新技術。

而是讓你在看見其他人的同時，終於也重新看見自己。

從這段經歷，我重新理解了什麼？

這段經歷最後留給我的，不是「女性工程師一定比較辛苦」這麼簡單的結論。

而是三件事。

第一，少數群體面對的困境，有時不是明確的排斥，而是長期缺乏歸屬感。

第二，**專業能力與展現專業的方式是兩件不同的事情。**組織不應該只用聲量、自我推銷能力或單一社交模式判斷一個工程師的價值。

第三，找到適合自己的社群非常重要。

好的社群不會只告訴你還缺少什麼，而會讓你透過其他人的經驗，更清楚知道自己已經擁有什麼。

這也是我第一次真正喜歡上 Women Who Code 這樣的女性科技社群的原因。

常見問題

Q2022 Taipei Women in Tech Honorees 是什麼？

2022 Taipei Women in Tech Honorees 是 Taipei Women in Tech 對科技女性工作者的公開表揚名單，讓不同背景、職涯路徑與專業領域的女性科技工作者被更多人看見。

Q我為什麼會獲得 Taipei Women in Tech Honorees 推薦？

我在 2021 年參與 Women Who Code Taipei，主持多場活動並擔任技術分享講者，之後受邀成為 WWC Taipei 核心志工。因為持續參與社群與技術分享，而獲得推薦參與選拔。

QWomen Who Code Taipei 對我的職涯有什麼影響？

最大的影響不是學到某一項特定技術，而是讓我接觸更多女性科技工作者，並重新理解工程師的專業價值、社群歸屬感，以及不同的職涯與專業表達方式。

Q女性工程師一定會遇到冒牌者症候群嗎？

不一定。但我在女性科技社群中發現，不少能力很好的女性工作者仍會懷疑自己的能力。對我而言，與不同女性科技工作者交流最大的幫助之一，就是重新辨識自己已經具備的能力與價值。

Q企業可以從女性工程師的職涯經驗學到什麼？

組織在評估工程人才時，不應只看誰最擅長表達、最常談論新技術或最容易融入主流社交圈。實際的問題解決能力、專案複雜度、跨領域理解與長期成果，也應該成為人才評估的重要依據。
