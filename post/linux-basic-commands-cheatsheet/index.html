Linux 基本操作指令介紹

整理 Linux 最常用的檔案與目錄操作指令，包含 pwd、ls、rm、chmod 等指令的用法與注意事項。

剛開始接觸 Linux 系統時，多數操作都要靠指令列完成，不像桌面系統可以用滑鼠點一點。這篇整理平常在檔案與目錄操作上最常用到的一批指令，從查看目前位置、切換目錄，到刪除、複製、找檔案、改權限，都是幾乎每天都會敲到的基本功。

如何查看與切換目錄？

pwd（print working directory）會顯示目前所在的目錄路徑，是確認「我現在在哪」最快的方法。cd（change directory）則是用來切換到另一個目錄，例如 cd /var/log 會跳到系統日誌所在的目錄，cd .. 則是回到上一層。

ls 怎麼看檔案，-a 跟 -al 差在哪？

ls 會列出目前目錄底下的檔案與資料夾名稱。單獨打 ls 只會顯示一般檔案，加上 -a 才會連隱藏檔（以 . 開頭的檔案，例如 .bashrc）一起列出來；再加上 -l 變成 -al，就會同時顯示檔案的權限、擁有者、大小、修改時間等詳細資料。實務上 ls -al 是最常用的組合，因為光看檔名往往不夠，權限跟大小才是排查問題時真正要看的資訊。

怎麼查看檔案內容？cat 跟 more 的差別

cat 會把檔案內容整段印出來，適合檔案不大的情況，例如快速看一下設定檔內容。但如果檔案很長，cat 印出來的內容會一口氣捲過螢幕，這時候可以改用 more，它會一頁一頁顯示，按空白鍵翻下一頁。常見用法是搭配管線一起用，例如目錄項目很多時：

ls -al | more

這樣就能一頁一頁瀏覽，不會被洗版。

建立、刪除、搬移檔案要用哪些指令？

檔案與目錄的基本操作指令整理如下：

指令用途範例
mkdir建立新目錄mkdir project
rm刪除檔案rm test.txt
rm -rf刪除整個目錄（含底下所有內容）rm -rf test
rmdir刪除空目錄rmdir empty_folder（目錄內有內容要改用 rm -rf）
mv移動或重新命名檔案／目錄mv a.txt b.txt
cp複製檔案cp a.txt backup.txt

rm -rf 是這幾個指令裡最需要小心的一個——它會不經確認直接刪掉整個目錄，沒有回收桶可以撿回來，下指令前最好先用 ls 確認自己真的在對的目錄、對的檔案上。

find 跟 whereis 找檔案有什麼不同？

find 是即時搜尋，會實際掃描指定路徑下的檔案系統，找得到最新建立的檔案，但目錄範圍大的時候會比較慢。whereis 則是查詢系統索引過的資料庫，速度快很多，不過缺點是它找不到不代表檔案真的不存在——資料庫可能還沒更新，或是那個檔案本來就不在它索引的範圍裡。兩者算是速度跟即時性的取捨：急著找剛建立的檔案用 find，找系統內建指令或套件位置通常用 whereis 就夠快。

怎麼管理檔案的權限與擁有者？

chmod 用來變更檔案的存取權限（可讀、可寫、可執行），chown 用來改變檔案的擁有者，chgrp 則是改變檔案所屬的群組。這三個指令常常一起出現在部署或多人共用主機的場景，例如把某個檔案的擁有者從 root 換成一般使用者，或是把某個 script 加上執行權限才能跑起來。

怎麼檢查硬碟空間跟網路狀態？

df（disk free）用來查看整台機器的硬碟空間使用情況，du（disk usage）則是查看某個目錄底下各個檔案／子目錄各自佔用了多少空間——两者常常搭配使用：df 先確認整體空間吃緊了，再用 du 找出是哪個目錄佔用最多。ifconfig 用來查詢目前網路卡的狀態，包含 IP 位址、子網路遮罩等資訊，是早期除錯網路連線問題的常用指令。

怎麼新增使用者？

adduser 加上使用者名稱可以在系統上新增一個帳號，例如 adduser username。新增後通常還需要搭配設定密碼、指定群組等後續步驟，才能讓這個帳號正常登入使用。

常見問題

Qrm 跟 rm -rf 什麼時候該用哪個？

單純刪除檔案用 rm 就好；要刪除整個目錄（尤其目錄底下還有子目錄或檔案）才需要加 -rf。因為 -rf 會強制且遞迴刪除、不會再次確認，下手前務必先確認路徑正確。

Qwhereis 找不到檔案，是不是代表檔案不存在？

不一定。whereis 只查詢系統既有的索引資料，索引沒更新的話，即使檔案存在也可能查不到。想確認檔案是否真的存在，應該用 find 直接掃描檔案系統。
